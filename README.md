# Linear Algebra Practical Projects

This repository contains practical programming assignments for a Linear Algebra course, focusing on the real-world applications of Singular Value Decomposition (SVD) and Eigenvectors[cite: 3, 4].

## Overview

The projects explore how core linear algebra concepts are implemented to solve complex computational problems[cite: 4]. The primary topics covered in this repository include:

*   **Geometric Intuition of SVD:** Decomposing transformation matrices into their fundamental geometric actions (rotation and scaling) applied to 3D and 2D spaces[cite: 4].
*   **Eigenfaces for Face Recognition:** Implementing the power iteration method with deflation to compute the top-$k$ eigenvectors of a covariance matrix, enabling dimensionality reduction and facial recognition[cite: 4].
*   **Web Search and PageRank:** Computing the dominant eigenvector of the Google matrix using power iteration to rank interconnected nodes[cite: 4].
